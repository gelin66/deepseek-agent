# ADR-0004：固定简体中文产品语言

- 状态：已接受
- 日期：2026-07-18

## 决策

本产品面向人的界面和 DeepSeek 自然语言提示固定使用简体中文。运行时不保存 locale，
不根据操作系统环境选择语言，不提供语言设置、首次启动语言步骤、运行时切换、其他语言包
或模型输出后处理翻译。

UI 消息目录与模型提示词组合保持解耦：前者只负责产品文案，后者负责 Agent 行为。协议
字段、配置键、命令、工具名、模型 ID、路径、代码、diff、stdout/stderr 和原始日志继续
使用稳定的机器契约或原始内容。

## 原因

- 产品是所有者自用的 DeepSeek 专用本地 Agent，多语言没有真实用户需求；
- locale 状态贯穿配置、首次启动、App、命令和组件，增加耦合但不提升任务成功率；
- 模型后处理翻译会增加一次模型调用、时延、成本和失败面；
- 固定中文可以删除传播和兼容逻辑，同时保留集中消息目录，避免把文案散落到 Rust 代码。

## 后果

- 只保留 `zh-Hans.json`；保留的 UI 文案必须收敛到 `tr(MessageId)`，当前迁移证据与
  尚待删除的旧界面以 `ROADMAP.md` 为准；
- 删除 Locale 类型、配置与环境解析、语言选择器、其他语言包和 `/translate`；
- 根/子 Agent、恢复会话和 Headless 人类文本不携带语言状态；
- 固定中文本身不宣称提升 Agent 能力；以后改变规划、工具、恢复、压缩或多 Agent 协作
  提示语义时，仍必须按评测规则做同任务 A/B；
- 若以后出现真实的多语言产品需求，必须以证据和新 ADR 重新决策，不能恢复旧兼容路径。
